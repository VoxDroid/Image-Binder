## Reporting Bugs

If you find a bug in Image Binder:

1. **Verify the Issue**:
   - Ensure you’re using the latest version from the [Releases page](https://github.com/VoxDroid/Image-Binder/releases).
   - Reproduce the issue to confirm it’s consistent.

2. **Submit a Bug Report**:
   - Open a new issue on the [Issues page](https://github.com/VoxDroid/Image-Binder/issues).
   - Use the bug report template and include:
     - A clear title and description.
     - Steps to reproduce the bug.
     - Expected vs. actual behavior.
     - Screenshots, logs, or error messages.
     - Your environment (e.g., Windows version, .NET Framework version).

3. **Follow Up**:
   - Respond to any questions or requests for clarification from maintainers.
   - Test any proposed fixes if requested.

## FAQs

**Q: Why does Image Binder skip some files when adding them?**  
A: Image Binder only processes JPG, JPEG, and PNG files. Files with other extensions are skipped, and you’ll see a message indicating this. Ensure your files are in a supported format.

**Q: How do I enable lossless mode?**  
A: Check the "Lossless Mode" checkbox in the Home tab. This disables compression, preserving original image quality at the cost of larger file sizes.

**Q: Why is the "Bind" button disabled?**  
A: The "Bind" button is disabled if no images are added to the list or if a binding process is already running. Add images or wait for the current process to complete.

**Q: Can I process images from multiple folders?**  
A: Yes! Use the "Select Folders" button to choose a directory, and Image Binder will include all supported images from that folder and its subfolders.

**Q: How do I clear metadata fields?**  
A: Click the metadata label (next to the title, author, subject, and keywords fields) to reset all fields to empty.

**Q: Why do I get an error when renaming files?**  
A: This may occur if the file is in use, lacks write permissions, or has an invalid path. Ensure you have permission to modify the files and that they’re not open in another program.

**Q: How can I support Image Binder?**  
A: You can contribute by reporting bugs, suggesting features, or donating via [Ko-fi](https://ko-fi.com/O4O6LO7Q1). See [Supporting the Project](#supporting-the-project) for details.
